    Device HTTP Stream

    /rest/v4/devices/{id}/media

    GET

    Opens an HTTP video stream from the Device. It is not exactly an API function but rather a URL format which may contain any Device id. Live stream and archive can be downloaded. If required and possible, media stream transcoding is performed on-the-fly.

    REST v4 (VMS 6.1+)
     3.0.0 
    OAS3

    Servers

    /rest/v4/devices/{id}/media - GET

    Opens an HTTP video stream from the Device. It is not exactly an API function but rather a URL format which may contain any Device id. Live stream and archive can be downloaded. If required and possible, media stream transcoding is performed on-the-fly.

    Parameters

    NameDescription
    stream
    string
    (query)

    If unspecified, Server auto-detects the preferred stream index based on the destination resolution.

    Possible values are:

    • "primary" High-resolution stream.
    • "secondary" Low-resolution stream.

    Available values : primary, secondary

    • --
    • primary
    • secondary
    positionMs
    (query)

    If present, specifies the Archive stream start position. Otherwise, the Live stream is provided.

    resolution
    string
    (query)

    Specifies the exact resolution to be used for the output video. The resolution format is {width}x{height} (for example, "320x240") or can be defined using a height-only format (for example, "240p"). When provided, this option ensures that the output is rendered at the specified resolution. If both this option and resolutionWhenTranscoding are supplied, this option takes precedence. If neither option is set, the following defaults apply: When transcoding is enabled: For low or undefined streams: use the default secondary-stream resolution. For high streams: use the lesser of 1080p and the high-stream's native resolution. When transcoding is not enabled: Use the primary stream's native resolution.

    resolutionWhenTranscoding
    string
    (query)

    Specifies the resolution to be used only if the video is transcoded. This option applies when transcoding is triggered (either through other transcoding settings or because the original stream's codec is incompatible with the client request). The resolution format is {width}x{height} (for example, "320x240") or can use a height-only format (for example, "240p"). If the resolution option is also provided, it will override this setting. If neither option is set, the following defaults apply: When transcoding is enabled: For low or undefined streams: use the default secondary-stream resolution. For high streams: use the lesser of 1080p and the high-stream's native resolution. When transcoding is not enabled: Use the primary stream's native resolution.

    rotation
    string
    (query)

    A transcoding option. Item rotation, in degrees. If the parameter is auto, the video will be rotated to the default value defined in the Device Settings dialog.

    Possible values are:

    • "auto"
    • "0"
    • "90"
    • "180"
    • "270"
    aspectRatio
    string
    (query)

    A transcoding option. Item aspect ratio, e.g. '4:3' or '16:9'. If the parameter is auto, the video aspect ratio would be taken from the default value defined in the Device Settings dialog. If the parameter is empty, it will force to don't transcode regardless of the option value in the Device Settings.

    dewarping
    boolean
    (query)

    A transcoding option. Image dewarping. If the parameter is absent, image dewarping will depend on the value in the Device settings dialog.

    • --
    • true
    • false
    dewarpingXangle
    number
    (query)

    A transcoding option. Dewarping pan in radians.

    dewarpingYangle
    number
    (query)

    A transcoding option. Dewarping tilt in radians.

    dewarpingFov
    number
    (query)

    A transcoding option. Dewarping field of view in radians.

    dewarpingPanofactor
    integer
    (query)

    A transcoding option. Dewarping aspect ratio correction multiplier (1, 2 or 4).

    zoom
    string
    (query)

    A transcoding option. Zooms the selected image region. The format is {x},{y},{width}x{height} with values in range [0..1].

    panoramic
    boolean
    (query)

    A transcoding option. Transcodes a multi-sensor camera into one stream.

    • --
    • true
    • false
    videoCodec
    string
    (query)

    Forces specific video codec. Causes error response if specified codec is not found or not supported for selected particular container (see format).

    quality
    string
    (query)

    Video quality.

    Available values : lowest, low, normal, high, highest, preset, undefined

    • --
    • lowest
    • low
    • normal
    • high
    • highest
    • preset
    • undefined
    endPositionMs
    (query)

    If present, specifies the Archive stream end position. It is used only if the positionMs parameter is present.

    dropLateFrames
    integer
    (query)

    Drop Late Frames.

    standFrameDuration
    boolean
    (query)

    Stand Frame Duration. If the parameter is present, the video speed is limited by the real time.

    • --
    • true
    • false
    realTimeOptimization
    boolean
    (query)

    Turn on the realtime optimization. It will drop some frames if there is not enough CPU for the realtime transcoding.

    • --
    • true
    • false
    audioOnly
    boolean
    (query)

    Send only the audio stream.

    • --
    • true
    • false
    accurateSeek
    boolean
    (query)

    Seek to the exact time in the Archive by the specified pos, otherwise seek to the nearest left to the pos keyframe (on timeline). Enabling causes the stream to be transcoded. Disabled by default.

    • --
    • true
    • false
    durationMs
    (query)

    Can be used for both live and archive streams - for archive streams effectively it's another way to specify endPositionMs.

    signature
    boolean
    (query)

    Add signature to exported media data, only mp4 and webm formats are supported.

    • --
    • true
    • false
    utcTimestamps
    boolean
    (query)

    Use absolute UTC timestamps in exported media data, only mp4 format is supported.

    • --
    • true
    • false
    continuousTimestamps
    boolean
    deprecated
    (query)

    Deprecated. Add continuous timestamps in exported media data. Always true, regardless of the parameter value.

    • --
    • true
    • false
    download
    boolean
    (query)

    Force to download file in browser instead of displaying it.

    • --
    • true
    • false
    _local
    boolean
    (query)

    If false or unspecified, the information in the response will be collected from other Servers in the Site as well. If specified as empty or true, then only the Server processing the request will provide information.

    Available values : true

    • --
    • true
    _strict
    boolean
    (query)

    If false or unspecified, the Server will produce available results, ignoring minor errors. If specified as empty or true, then the request will fail on any error.

    • --
    • true
    • false
    _ticket
    string
    (query)

    One-time authorization ticket previously generated using Login REST API obtained from the current Server.

    id *
    string
    (path)

    Device id (can be obtained from "id", "physicalId" or "logicalId" field via GET /rest/v4/devices) or MAC address (not supported for certain cameras).
